# تطبيق شبكة القناص (AlqanasNet Android App)

تطبيق أندرويد أصلي مبني بـ **Kotlin + Jetpack Compose** ومربوط مع:
1. راوتر التوزيع مايكروتك (`https://alqanas.cc.cd`) لتسجيل الدخول، تغيير السرعة، حجب تحديثات جوجل، ومتابعة الاستهلاك.
2. سيرفر الإدارة المستقل (`alqanas_app_server`) لجلب الباقات، تعريف أحجام البروفايلات، وإرسال الإشعارات المحلية للمتصلين.

## تعديل رابط سيرفر الإدارة قبل البناء
افتح الملف:
`app/src/main/java/com/example/model/HotspotModels.kt`
وعدّل قيمة `ADMIN_SERVER_URL` لتطابق عنوان سيرفر الإدارة لديك (الافتراضي: `http://172.16.255.10:5055` أو استخدم نطاق HTTPS مثل `https://app.alqanas.cc.cd`).

## طريقة استخراج ملف APK تلقائياً عبر GitHub Actions
1. أنشئ مستودعاً (Repository) جديداً على GitHub (عام أو خاص).
2. ارفع محتويات هذا المجلد كاملة إلى المستودع.
3. ادخل إلى تبويب **Actions** في GitHub، وستجد مهمة **Build AlqanasNet APK** تعمل تلقائياً.
4. بعد انتهائها (حوالي 3-5 دقائق)، نزّل ملف **AlqanasNet-Debug-APK** من أسفل صفحة المهمة (Artifacts) وثبّته على الأندرويد.
